# 岛仔 Daozai · 发布页

本仓库只存放岛仔的安装包与更新包，源代码不在公开仓库。

## 下载

- 最新版本：见本仓库 **Releases**
- 安装包：`Daozai-Setup-vX.Y.Z-x64.exe`
- 免安装版：`Daozai-vX.Y.Z-windows-x64.zip`（应用内更新同样使用这个包）
- 校验和：`SHA256SUMS.txt`

## 更新与反馈

- 应用内「设置 → 关于 → 检查更新」；更新包从本仓库 Release 下载，并校验 SHA-256。
- 建议与问题：应用内「设置 → 关于 → 意见反馈」，按模板发送到反馈邮箱即可。
