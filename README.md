## 下载

#### - v0.6.68

- 安装包：`Daozai-Setup-v0.6.68-x64.exe`

- 校验和：`SHA256SUMS.txt`

######    更新与反馈

- 增加更新和反馈

	- 应用内「设置 → 关于 → 检查更新」；更新包从本仓库 Release 下载，并校验 SHA-256。

	- 建议与问题：应用内「设置 → 关于 → 意见反馈」，按模板发送到反馈邮箱即可。
